# Ruta Tángara

Sitio web de un cliente ficticio que organiza salidas de avistamiento de aves cerca de Bogotá.
Proyecto académico de la asignatura **Electiva I – Diseño de aplicaciones web I** (Corporación Universitaria Iberoamericana).

Autoras: Wendy Jelitza Torres Jimenez y Sofi Yanina Chilatra Tapiero.

## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: ecosistemas, próximas salidas, calendario y video |
| `salidas.html` | Listado con filtro por nivel y orden |
| `salida.html?id=...` | Ficha de cada salida (galería, pestañas, canto del ave) |
| `guias.html` | Equipo, compromisos y código de conducta |
| `inscripcion.html` | Formulario con validación y cálculo del total |
| `confirmacion.html` | Número de inscripción y resumen |
| `contacto.html` | Canales, mapa, horario y preguntas frecuentes |
| `glosario.html` | Términos técnicos explicados |
| `proyecto.html` | Video de la creación del sitio y créditos |

## Estructura

- `css/estilos.css`: todos los estilos (variables de color en `:root`).
- `js/datos.js`: datos de las seis salidas.
- `js/app.js`: interacción del sitio. La constante `VIDEO_PROYECTO`, al inicio, guarda el enlace de YouTube del video.
- `img/`: ilustraciones SVG propias y capturas.
- `media/`: videos ilustrativos (MP4).
- `fonts/`: fuentes Lora y Poppins (licencia SIL OFL 1.1).

Ruta Tángara es un negocio ficticio: fechas, precios, guías y datos de contacto son ilustrativos. Los lugares, las aves, los datos de conservación y las grabaciones (xeno-canto) son reales y se citan en el sitio.
